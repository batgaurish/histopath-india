# Image attribution

Every micrograph in this folder must be listed here with its source and
licence. Licences that forbid derivative works (e.g. CC BY-NC-ND) cannot be
used: the game slices each image into puzzle tiles, which is a derivative.

## Share-alike obligation

CC BY-NC-SA is *viral*: derivatives must carry the same licence. The puzzle
tiles generated from `st_m2.jpg` are derivatives, so that image and its tiles
remain CC BY-NC-SA 3.0 even though the surrounding source code does not.

## Non-commercial obligation

CC BY-NC-SA images may not be used commercially. This project must stay free
to students for these images to remain usable.
